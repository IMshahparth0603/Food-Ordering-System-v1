# Food-Ordering-System-v1
A console-based food ordering system built with Java.
<br><br>

## Project Scope:
> Developed as an academic exercise to practice core ***Java fundamentals from Semester 1***, prioritizing clear conceptual implementation over performance optimization.

<br>

## How to Run

1. Make sure you have JDK 18 or higher installed (this project was developed using OpenJDK 18.0.2). You can check your version with:
```bash
   java -version
```
2. Clone this repository.
3. Compile them all and then run "Main" class (all files in same folder):
```bash
   javac <file_name>.java
```
4. Execute program:
```bash
   java Main
```
5. Alternatively, open the project folder directly in an IDE (such as IntelliJ IDEA, Eclipse, or VS Code) and run Main.java.
